# Feature

Используй текущий запрос пользователя как задачу.

Прочитай `docs/ai-workflow/README.md`, `docs/ai-workflow/routing.md` и единый
контракт `docs/ai-workflow/feature.md`, затем выполни контракт.

Когда контракт требует отдельную роль, используй одноимённый project custom
agent из `.codex/agents/` или отдельного bounded-субагента в свежем контексте.
Передавай только id задачи, текущий этап, нужные пути и разрешённую зону записи.
Выбирай уровень модели `deep/standard/fast` по `routing.md`; QA и review не
выполняй в контексте автора проверяемого артефакта.
