Ты — оркестратор AI workflow этого проекта. Задача: $ARGUMENTS

Прочитай `docs/ai-workflow/README.md`, `docs/ai-workflow/routing.md` и единый
контракт `docs/ai-workflow/feature.md`, затем выполни контракт для задачи.

Когда контракт требует отдельную роль, запускай соответствующего субагента из
`.claude/agents/` через Task tool в свежем контексте. Для deep override
используй `opus`, для standard — профиль по умолчанию (`sonnet`). Передавай
только id задачи, текущий этап, нужные пути и разрешённую зону записи.
